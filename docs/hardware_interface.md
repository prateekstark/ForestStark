# Hardware interface

Generated by `ros2 run fs_bringup interface_contract` from the topics the simulator bridges (`fs_bringup/sim.py`) and the joint limits in the URDF. A machine's drivers serve these topics under the robot's namespace and `ros2 launch fs_bringup robot.launch.py` runs the same autonomy nodes the simulator tests. Frames: `<ns>/base_link` etc. from robot_state_publisher; `map` is the site's ENU frame at the surveyed origin.

## Katar

| Topic (in the robot's namespace) | Type | Driver | Contents |
|---|---|---|---|
| `odom` | `nav_msgs/msg/Odometry` | publishes | wheel / track odometry in the robot's odom frame, 50 Hz |
| `imu` | `sensor_msgs/msg/Imu` | publishes | chassis IMU, 100 Hz, gravity included |
| `gnss/fix_raw` | `sensor_msgs/msg/NavSatFix` | publishes | receiver fix with covariance, 5-10 Hz; RTK fix as STATUS_GBAS_FIX |
| `joint_states` | `sensor_msgs/msg/JointState` | publishes | every joint of the URDF, 50 Hz (robot_state_publisher builds TF from it) |
| `auger/status` | `std_msgs/msg/String` | publishes | JSON, 20 Hz: phase (idle lowering boring bored refusal no_ground retracting stopped held), depth, collapse, open_depth, target, stroke, feed, thrust, torque, power, energy_kj, thrust_limited, in_rock, in_pan, hole [x, y] |
| `plugs/status` | `std_msgs/msg/String` | publishes | JSON, 5 Hz: per carrier count, cells, next, occ ('1' per full cell), next_local / next_angle; per holder whether it holds a plug |
| `terramechanics` | `std_msgs/msg/String` | publishes | JSON, 10 Hz: per wheel load N, sinkage z, slip, rut; mean slip, motion resistance (on a machine: from drive currents and the odometry / GNSS speed) |
| `scan` | `sensor_msgs/msg/LaserScan` | publishes | planar lidar, 10 Hz, in its own frame from the URDF |
| `cmd_vel` | `geometry_msgs/msg/Twist` | subscribes | Twist from the safety monitor only; the drive stops if none arrives for 0.5 s |
| `auger/cmd` | `std_msgs/msg/String` | subscribes | "bore <m>" \| "pick <m>" \| "retract" \| "stop" \| "hold" \| "resume" \| "wet <litres>"; the feed controller stops on refusal (rock) and reports it |
| `plugs/cmd` | `std_msgs/msg/String` | subscribes | "pick <carrier> <cell\|next> <holder>" \| "move <from> <to>" \| "drop <holder>" \| "fill <carrier> [n]" \| "empty <carrier> [n]" |
