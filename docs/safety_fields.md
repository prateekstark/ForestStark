# Safety scanner field sets

Generated by `ros2 run fs_bringup safety_fields` (sizing in `fs_autonomy/safety_fields.py`, reasoning in [safety_concept.md](safety_concept.md)). Protective field length beyond the footprint `S = v T + 1.1 v^2 / 2a + Z`. Polygons for every field set, in base_link and in each scanner's frame, are in `safety_fields.yaml`.

## In normal operation

The comfort layer (the software safety monitor) slows from 6 m and stops for a person in the path at 2.5-3 m, for an object at 0.5-1.5 m depending on speed; the protective fields are shorter at every speed the navigators use, so the certified layer only acts when the software has not (a fault, a person stepping out from behind something within its reach). The simulator runs the PLC logic on the same scans (`plc_model`) and counts its trips: in normal runs there should be none.
